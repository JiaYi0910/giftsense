1系統概述

GiftSense 讓家人用一個平台照顧遠方的親友：每日依天氣與病況產生關懷提醒、用 AI 守護助理檢查保健品是否撞藥、從連鎖藥局比價挑選合適商品，並透過 LINE 把關懷卡送到親友手上。

4 種使用端：網頁、Android、iPhone、親友 LINE
55 支後端 REST API
12 項暖心選物商品（四大藥局官網實際查價）
36 篇實證文獻與照護指引＋18 條交互作用規則

主要功能

模組說明
今日守護中央氣象署即時天氣、依親友病況與語氣（撒嬌／台語／端莊）產生關懷叮嚀、3 秒發送關懷卡、連續守護天數、用藥安全雷達與專屬快速提問。
AI 守護助理RAG 檢索實證文獻 ＋ TFDA 交互作用規則，判斷保健品與親友用藥是否衝突，給出機轉、引用與安全的商品建議；每日 3 次，可用暖幣兌換。
暖心選物依親友病況比對商品（主要病況加權、禁忌病況排除），固定推薦 3 項，四大連鎖藥局比價並標示同規格最低價；購物回饋（ShopBack 模式，模擬流程：金額依查價鎖定，使用者無法修改）。
傳情小站家人 × 親友的一對一聊天室；訊息同步推播到親友 LINE，親友從 LINE 回覆會回到聊天室。
暖幣存摺關懷卡、小熊互動、購物回饋累積點數；1 點可折抵 $1（與回饋比例一致），也可兌換 AI 守護詢問次數，效期 3 年。
管理後台系統總覽、實證文獻庫（新增／編輯／刪除即時更新 RAG）、RAG 測試台（測試情境＋深度題、不限次數）、回饋審核（待入帳期間駁回異常回饋）、後端設定。

安全設計

項目做法
密碼以 bcrypt 雜湊儲存，資料庫不保存明文；舊資料於啟動時自動轉換。
第三方登入後端驗證 Google／Facebook／Apple 的憑證，不信任前端傳來的身分。
會員身分任何方式登入成功後核發 HMAC 簽章的會員通行證（30 天），App 以 Authorization: Bearer 送出；後端只依通行證判斷帳號，冒用別人的帳號一律拒絕，過期就回到登入頁。簽章金鑰來自環境變數 AUTH_TOKEN_SECRET。
管理員密碼由 ADMIN_PASSWORD 設定；登入後另核發管理員通行證（7 天），管理後台（文獻庫、RAG 設定、資料庫匯出、購物回饋審核）必須持有，RAG 測試台憑證不限次數。
LINEWebhook 以 LINE_CHANNEL_SECRET 驗證 X-Line-Signature，未設定金鑰時一律拒絕；一個 LINE 帳號只綁定一位親友。
購物回饋金額在「前往購買」時由後端依商品查價鎖定，確認購買的 API 不接受金額；每天最多確認 3 筆，待入帳 7 天內管理員可駁回。
隱私網頁版 Cookie 同意（必要／第三方登入）、公開隱私權政策 /privacy；聊天只看得到自己與親友的對話。

所有點數由後端計算與控管上限，前端只負責顯示。

項目點數規則與上限
註冊新會員註冊獎勵+5帳密註冊或第一次用 Google／Facebook 登入時發放一次
關懷發送關懷卡+0.1每位親友每天 1 次；每天最多 5 張，即每天最多 0.5 點（領取鍵 care_card:日期:親友）

購物購物回饋依金額見下方公式；金額依查價鎖定，確認購買後待入帳 7 天自動入帳
設計原則（2026/10/15 調整）：參考蝦皮蝦幣與 ShopBack，1 點折抵 $1，點數主要來自購物回饋；註冊與日常互動只給小額點數（每月最多約 17 點），避免一開始就能折抵太多。點數保留到小數第 2 位，折抵時以整數點計算。舊紀錄已依新規則換算（100 → 5、10 → 0.1、50 → 0.5、兌換 −50 → −1）。

購物回饋公式

回饋點數 ＝ 四捨五入（藥局查價金額 × 藥局回饋比例）　·　回饋 $1 ＝ 1 點 ＝ 折抵 $1
藥局回饋比例計算範例回饋點數
大樹藥局5%挺立 UC-II $849 × 5% = 42.4542 點
杏一醫療4%亞培勝補納 $2,790 × 4% = 111.6112 點
啄木鳥藥局3%桂格完膳 $1,390 × 3% = 41.742 點
丁丁藥局3%桂格完膳 $1,368 × 3% = 41.0441 點

其他藥局預設 3%。四捨五入採 Python round()（剛好 .5 時取偶數）。

金額不可更動：點「前往購買」時，後端依商品名稱與藥局從商品資料庫取出查價金額並鎖定，App 不送價格；確認購買的 API 也不接受任何金額欄位。沒有查價資料的商品不提供回饋。
防重複入帳：自動入帳時以「狀態仍為待入帳」作為更新條件，同一筆只會入帳一次。
防刷點數：每位會員每天最多確認 3 筆購買，同一商品在同一藥局每天 1 筆（上限檢查與狀態更新在同一個條件更新中完成，同時送出也不會超過）。
管理員審核：待入帳期間，管理後台「回饋審核」列出所有會員的待入帳回饋，發現退貨或異常購買時填寫原因駁回（不給點數），會員會看到「未通過審核」與原因；期滿已自動入帳的回饋不能駁回。

9Demo 腳本

建議順序：網頁版（完整功能＋管理後台）→ Android 模擬器 → iPhone。總長約 18–20 分鐘。

事前準備

  • 上台前 3 分鐘先開啟網站，喚醒 Render（免費方案閒置會休眠，第一次載入約 30–60 秒）。
  • 會員帳號：已建立親友（例如「家宜（熬夜）」）並完成 LINE 綁定。
  • 管理員帳號：admin，密碼為 Render 的 ADMIN_PASSWORD（不要寫在簡報上）。
  • 一支手機登入已綁定的 LINE，扮演「親友」。
  • 確認首頁天氣顯示「中央氣象署 · 臺北站 hh:mm 觀測」。
  • Android：啟動模擬器 Giftsense_Pixel_7，安裝最新 APK，先在模擬器相機拍一張照片（換頭貼用）。
  • iPhone：Safari 已開過網站並「加入主畫面」（或現場示範加入）。
  1. 1 分登入頁與隱私
    開啟網站 → 下方出現 Cookie 同意橫幅 → 點「自訂設定」展示必要／第三方登入兩類 → 「接受全部」。點 Apple 按鈕展示「尚未開放」，再用帳號密碼登入。
    網頁版尊重使用者的 Cookie 選擇，沒有廣告追蹤；隱私權政策有公開網頁 /privacy。
    藍色流動背景、登入卡片淡入。

    每位親友、每天、每種語氣的叮嚀都不同，會結合當地天氣與病況。
    一頁塞滿不用捲動，卡片依序進場。
  3. 2 分發送關懷卡 × LINE
    按「3 秒發送健康關懷卡」→ 成功視窗（+0.1 點）→ 「前往傳情小站」。拿出扮演親友的手機：LINE 收到 Flex 關懷卡 → 在 LINE 回覆「謝謝」。

  4. 2 分AI 守護助理

    結合 RAG 實證文獻與 TFDA 交互作用規則，先檢查會不會撞藥。

  5. 3 分暖心選物 × 購物回饋

可能被問到建議回答
資料會不會因為伺服器重啟消失？資料存在 Turso 雲端資料庫，Render 休眠或重新部署都不影響。
AI 的建議可靠嗎？以實證文獻（NIH、AHA、TFDA 等）做 RAG 檢索，再套用 TFDA 交互作用規則；有疑慮一律建議諮詢醫師，不提供未查價或有禁忌的商品。
價格從哪裡來？2026/10/13 逐一到四家連鎖藥局官網查價；包裝不同或缺貨的報價會顯示但不參與比價。
點數怎麼算？參考蝦皮與 ShopBack：註冊 +5、關懷卡 +0.1、小熊每週 +0.5，點數主要來自購物回饋（依藥局 3–5% 換算，回饋 $1 = 1 點，經確認才入帳）；折抵 1 點 = $1。
親友一定要裝 App 嗎？不用，親友用 LINE 官方帳號輸入綁定碼即可接收關懷卡與回覆。
隱私怎麼保護？每次呼叫 API 都以登入通行證確認身分，只看得到自己的親友、聊天與點數；網頁版 Cookie 可自行選擇；管理後台需管理員密碼與簽章通行證。
