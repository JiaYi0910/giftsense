- [x] 實證文獻檢索（RAG）：15 篇保健成分文獻加上 21 篇用藥安全與照護指引，共 36 篇

- [x] 快速提問依 22 類病況分類、共 104 題，每題都驗證會檢索到對應資料（`backend/tests/test_quick_questions.py`）
- [x] 每天 3 次，可用 1 點兌換 3 次
- [x] 管理員的 RAG 測試台不限次數，附有深度測試題

- [x] 購物回饋（模擬）：前往藥局網站，回到 App 確認購買後點數入帳
