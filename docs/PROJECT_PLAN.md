- [x] 中央氣象署即時天氣（已確認連線正常）
- [x] 依病況和語氣產生關懷叮嚀，3 秒送出關懷卡
- [x] 用藥安全雷達和快速提問
- [x] 首頁滿版、不用往下捲；藍色主題、動畫、全站對齊

### AI 守護助理
- [x] 實證文獻檢索（RAG）：15 篇保健成分文獻加上 21 篇用藥安全與照護指引，共 36 篇
- [x] 18 條藥物／食物／保健品交互作用規則（修正高血壓、糖尿病的誤判）
- [x] 快速提問依 22 類病況分類、共 104 題，每題都驗證會檢索到對應資料（`backend/tests/test_quick_questions.py`）；資料庫裡的文獻已和程式碼同步，正式站也是 104/104
- [x] 文獻庫查不到相關資料時顯示「尚未收錄」，不顯示評分和商品
- [x] 每天 3 次，可用 1 點兌換 3 次
- [x] 管理員的 RAG 測試台不限次數，附有深度測試題

### 暖心選物與暖幣
- [x] 12 項商品，四大連鎖藥局實際查價（2026/10/13）
- [x] 依病況比對推薦，固定顯示 3 項，標示首選和同規格最低價
- [x] 購物回饋（模擬）：點「前往購買」時後端依查價鎖定金額，回到 App 確認購買（金額不能改），待入帳 7 天後自動入帳；每天最多確認 3 筆，同商品同藥局每天 1 筆
- [x] 回饋 $1 = 1 點，折抵 1 點 = $1，點數效期 3 年
- [x] 贈點改為小額（參考蝦皮與 ShopBack）：註冊 +5、關懷卡 +0.1、小熊每週 +0.5，點數可到小數第 2 位
