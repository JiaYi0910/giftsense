1系統概述

GiftSense 讓家人用一個平台照顧遠方的親友：每日依天氣與病況產生關懷提醒、用 AI 守護助理檢查保健品是否撞藥、從連鎖藥局比價挑選合適商品，並透過 LINE 把關懷卡送到親友手上。

4 種使用端：網頁、Android、iPhone、親友 LINE
54 支後端 REST API
12 項暖心選物商品（四大藥局官網實際查價）
15 篇實證文獻＋8 條 TFDA 交互作用規則

主要功能

模組說明
今日守護中央氣象署即時天氣、依親友病況與語氣（撒嬌／台語／端莊）產生關懷叮嚀、3 秒發送關懷卡、連續守護天數、用藥安全雷達與專屬快速提問。
AI 守護助理RAG 檢索實證文獻 ＋ TFDA 交互作用規則，判斷保健品與親友用藥是否衝突，給出機轉、引用與安全的商品建議；每日 3 次，可用暖幣兌換。
暖心選物依親友病況比對商品（主要病況加權、禁忌病況排除），固定推薦 3 項，四大連鎖藥局比價並標示同規格最低價；購物回饋（ShopBack 模式，模擬）。
傳情小站家人 × 親友的一對一聊天室；訊息同步推播到親友 LINE，親友從 LINE 回覆會回到聊天室。
暖幣存摺關懷卡、小熊互動、購物回饋累積點數；1 點可折抵 $1（與回饋比例一致），也可兌換 AI 守護詢問次數，效期 3 年。
管理後台系統總覽、實證文獻庫（新增／編輯／刪除即時更新 RAG）、RAG 測試台（測試情境＋深度題、不限次數）、後端設定。

安全設計

項目做法
第三方登入後端驗證 Google／Facebook／Apple 的憑證，不信任前端傳來的身分。
管理員密碼由 ADMIN_PASSWORD 設定；登入後核發 HMAC 簽章通行證（7 天），RAG 測試台憑證不限次數。
LINEWebhook 驗證 X-Line-Signature；一個 LINE 帳號只綁定一位親友。
隱私網頁版 Cookie 同意（必要／第三方登入）、公開隱私權政策 /privacy；聊天只看得到自己與親友的對話。

6點數回饋計算（暖幣）

所有點數由後端計算與控管上限，前端只負責顯示。

獲得點數

項目點數規則與上限
註冊新會員註冊獎勵+100帳密註冊或第一次用 Google／Facebook 登入時發放一次
關懷發送關懷卡+10每位親友每天 1 次；每天最多 5 張（領取鍵 care_card:日期:親友）
互動小熊每週加碼+50點首頁小熊兩下；每週（ISO 週）1 次
購物購物回饋依金額見下方公式；須完成購買並經藥局確認才入帳

購物回饋公式

回饋點數 ＝ 四捨五入（實付金額 × 藥局回饋比例）　·　回饋 $1 ＝ 1 點 ＝ 折抵 $1
藥局回饋比例計算範例回饋點數
大樹藥局5%挺立 UC-II $849 × 5% = 42.4542 點
杏一醫療4%亞培勝補納 $2,790 × 4% = 111.6112 點
啄木鳥藥局3%桂格完膳 $1,390 × 3% = 41.742 點
丁丁藥局3%桂格完膳 $1,368 × 3% = 41.0441 點

其他藥局預設 3%。四捨五入採 Python round()（剛好 .5 時取偶數）。

  1. 1 分登入頁與隱私
    開啟網站 → 下方出現 Cookie 同意橫幅 → 點「自訂設定」展示必要／第三方登入兩類 → 「接受全部」。點 Apple 按鈕展示「尚未開放」，再用帳號密碼登入。
    網頁版尊重使用者的 Cookie 選擇，沒有廣告追蹤；隱私權政策有公開網頁 /privacy。
    藍色流動背景、登入卡片淡入。
  2. 2 分今日守護（首頁滿版）
    介紹天氣卡（中央氣象署即時觀測與測站時間）→ 整合關懷叮嚀切換「撒嬌／台語／端莊」、按「換一句」→ 點小熊兩下領 +50 → 安全雷達的專屬快速提問。
    每位親友、每天、每種語氣的叮嚀都不同，會結合當地天氣與病況。
    一頁塞滿不用捲動，卡片依序進場。
  3. 2 分發送關懷卡 × LINE
    按「3 秒發送健康關懷卡」→ 成功視窗（+10 點）→ 「前往傳情小站」。拿出扮演親友的手機：LINE 收到 Flex 關懷卡 → 在 LINE 回覆「謝謝」。
    親友不需要安裝 App，用熟悉的 LINE 就能收到並回覆。
    約 15 秒內，「謝謝」出現在聊天室左側，時間正確、最新在最下方。
  4. 2 分AI 守護助理
    點專屬快速提問（例如「常熬夜要補什麼？」）→ 顯示實證文獻、安全雷達、對應商品卡（實際查價）。說明每日 3 次、50 點兌換 3 次。
    結合 RAG 實證文獻與 TFDA 交互作用規則，先檢查會不會撞藥。
    回覆附文獻引用與四大藥局比價。
  5. 3 分暖心選物 × 購物回饋
    展示「最推薦」商品、同規格最低價（米黃標示）、「日常保養推薦」補滿 3 項 → 點「前往最低價」開啟藥局網站 → 切回 GiftSense → 「完成購買了嗎？」→ 已完成購買 → 藥局確認中 → +N 點 → 開暖幣存摺看明細。
    商品依病況比對，有禁忌的不推薦（例如服用抗凝血劑不推薦魚油）；回饋採 ShopBack 模式，目前為模擬流程。
    金幣動畫與點數跳動，存摺出現「已入帳」。
  6. 1 分個人資料與頭貼
    帳號選單 → 個人資料設定 → 點頭貼上傳照片；說明 Google／Facebook 會自動帶入大頭照。

可能被問到建議回答
資料會不會因為伺服器重啟消失？資料存在 Turso 雲端資料庫，Render 休眠或重新部署都不影響。
AI 的建議可靠嗎？以實證文獻（NIH、AHA、TFDA 等）做 RAG 檢索，再套用 TFDA 交互作用規則；有疑慮一律建議諮詢醫師，不提供未查價或有禁忌的商品。
價格從哪裡來？2026/10/13 逐一到四家連鎖藥局官網查價；包裝不同或缺貨的報價會顯示但不參與比價。
點數怎麼算？關懷卡 +10、小熊每週 +50、購物回饋依藥局 3–5% 換算（回饋 $1 = 1 點），經確認才入帳；折抵也是 1 點 = $1，兩邊一致。
親友一定要裝 App 嗎？不用，親友用 LINE 官方帳號輸入綁定碼即可接收關懷卡與回覆。
隱私怎麼保護？聊天只看得到自己與親友的對話；網頁版 Cookie 可自行選擇；管理後台需管理員密碼與簽章通行證。
