基礎架構與部署7

  • Flutter 前端（3.47.7），同一套程式碼產出網頁版、Android 和 iOS App
  • FastAPI 後端部署在 Render，推送 GitHub main 後自動部署
  • Turso 雲端資料庫，Render 重啟也不會掉資料（設定見 TURSO_SETUP.md）
  • 後端改用 SQLAlchemy ORM：同一套程式可連線 SQL Server、Turso 或 SQLite，由 DATABASE_URL 決定；本機開發與展示使用 SQL Server（資料庫 GiftSense），正式站維持 Turso（設定見 SQLSERVER_SETUP.md）
  • 切換到空的資料庫時，第一次啟動會自動從 Turso（或 caregift.db）匯入全部資料；也可用 backend/tools/copy_database.py 手動複製
  • 伺服器使用台灣時間
  • 舊點數紀錄已清除並依新規則換算，聊天時間已校正

  • Google 登入

  • 用藥安全雷達和快速提問
  • 首頁滿版、不用往下捲；藍色主題、動畫、全站對齊

AI 守護助理6

  • 實證文獻檢索（RAG）：15 篇保健成分文獻加上 21 篇用藥安全與照護指引，共 36 篇
  • 18 條藥物／食物／保健品交互作用規則（修正高血壓、糖尿病的誤判）
  • 快速提問依 22 類病況分類、共 104 題，每題都驗證會檢索到對應資料（backend/tests/test_quick_questions.py）；資料庫裡的文獻已和程式碼同步，正式站也是 104/104
  • 文獻庫查不到相關資料時顯示「尚未收錄」，不顯示評分和商品
  • 每天 3 次，可用 1 點兌換 3 次
  • 管理員的 RAG 測試台不限次數，附有深度測試題

暖心選物與暖幣5

  • 12 項商品，四大連鎖藥局實際查價（2026/10/13）
  • 依病況比對推薦，固定顯示 3 項，標示首選和同規格最低價
  • 購物回饋（模擬）：點「前往購買」時後端依查價鎖定金額，回到 App 確認購買（金額不能改），待入帳 7 天後自動入帳；每天最多確認 3 筆，同商品同藥局每天 1 筆
  • 回饋 $1 = 1 點，折抵 1 點 = $1，點數效期 3 年
  • 贈點改為小額（參考蝦皮與 ShopBack）：註冊 +5、關懷卡 +0.1、小熊每週 +0.5，點數可到小數第 2 位

  • 正式站是否改用雲端 SQL Server：目前 SQL Server 只在本機使用；要切換需另外準備雲端 SQL Server（例如 Azure SQL）並確認費用，切換時會自動從 Turso 匯入，步驟見 SQLSERVER_SETUP.md
  • iPhone 上的 App 要更新：目前裝的是會員通行證上線前的版本，親友、聊天、點數等會員功能會讀取失敗；到 Mac 重跑 flutter run --release 才會換成新版（含新的購物回饋流程）
  • iOS 的 Google／Facebook 原生登入：要在 Google Cloud 建立 iOS OAuth 用戶端、在 Meta 新增 iOS 平台（Bundle ID com.jiayi.giftsense），目前 iOS App 先用帳號密碼登入
  • Apple 登入：需要 Apple Developer Program（每年 US$99）；目前採免費方式，只顯示「尚未開放」，要不要做待決定
  • 對照隊友的待辦清單（.docx）：隊友的修改已於 2026/10/08 合併，清單上是否還有未處理的項目需再確認
